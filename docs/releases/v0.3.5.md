# Mahiro Format v0.3.5

## What's new / 新增功能

- PDF → Word（DOCX）：提取文本和表格，生成标准 Word 文档（之前只有 TXT/HTML）
- 视频 → GIF 动图；WebP 动图 → GIF（保留帧数）
- XLSX/XLSM → XLS 老版 Excel 兼容格式
- ZIP → PDF：把压缩包里的图片合并成一个 PDF（防路径穿越）
- PPT/WPS → PNG/JPG：逐页转图并打包成 ZIP
- PDF 拆分 / 解密：PDF→PDF 时可选拆分每页或输入密码解密
- PDF→Excel 质量门禁：拍照扫描件 OCR 置信度过低时**明确报错说明原因**（模糊/倾斜/阴影），不再输出乱码表格

## Highlights

- PDF → Word (DOCX) with extracted text and tables
- Video → GIF; animated WebP → GIF
- XLSX/XLSM → legacy XLS
- ZIP → PDF: merge images inside a ZIP into one PDF (zip-slip protected)
- PPT/WPS → PNG/JPG page images in a ZIP
- PDF split / decrypt actions with local password handling
- PDF→Excel quality gate: low-confidence scanned pages fail with a clear bilingual reason instead of emitting garbage workbooks
