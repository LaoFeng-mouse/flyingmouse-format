# FlyingMouse Format v0.6.7（商店公开版）

## 修复
- **保存不再报 404**：转换产物在程序运行期间**永不过期**——放多久都能保存；退出软件时才清理临时文件，下次启动自动回收残留。
- **批量保存不再一票否决**：个别文件失败会跳过并列出明细，不再整批报失败；程序重启后的失效提示更明确。
- **单实例锁**：二次启动自动聚焦已有窗口，杜绝双开互踩导致产物丢失。
- **图片拼的 PDF / 扫描件 PDF 转 Word**：结构化识别失败时自动回落 OCR 文字识别，大概率直接出可用 Word；转 Excel 无表格时的报错补充「改转 Word / TXT」指引。
- **OFD 批量转换**：修复第 2 个及以后 OFD 转 PDF 文字层失效问题。
- **上传文件名**：多语言（韩/阿/俄/emoji）不再乱码，西欧 latin1 文件名不再被误转。
