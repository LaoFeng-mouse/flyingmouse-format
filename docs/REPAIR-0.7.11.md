## CR2 解码器修复

已在公开 EOS M100 原片上复现 dcraw 9.28 的 0xC0000005 崩溃。Windows 10/11 x64 的 CR2 改用官方 LibRaw 0.22.2 dcraw_emu + libraw.dll，并使用相机白平衡；其他 RAW 保留既有 dcraw 路径。随包提供所需的三个 VC143 运行库、许可及完整上游源码归档。Win7 派生排除此新引擎，未宣称本修复对 Win7 生效。

构建前执行 `npm run restore:libraw`，从 `libraw-engine-lock.json` 锁定的 LibRaw ZIP 和微软 CRT VSIX 自动恢复引擎。归档与最终文件均校验 SHA-256，只解包而不执行系统安装器；离线时仍可执行 `node scripts/restore-libraw.js <zip路径> <Microsoft.VC143.CRT x64目录>`。打包前继续逐文件核对锁定摘要；源码同步不表示已经发布二进制。

图片内存预算仍生效；内存不足导致的 IMAGE_PIXELS_EXCEEDED 与解码器崩溃分开验收，不移除保护、不缩小原图伪装成功。
