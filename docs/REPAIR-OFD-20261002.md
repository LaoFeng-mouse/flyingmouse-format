# OFD 空白结果与诊断修复（0.8.1 R5）

作者：牢蜂（LaoFeng）。仅供个人免费使用，禁止商业售卖、转卖和套壳。

## 问题与修复

旧代码仅以 PDF 文件存在且非空判断成功。受控 OFD 已复现资源 BaseLoc 被忽略、等价命名空间失效、同层对象重排导致白背景盖字，以及缺资源/页被静默略过；HTTP 仍返回成功。来源版本的旧安装载荷与被测代码摘要一致。此处不依赖用户原文件，用户原 OFD 的具体触发尚未实测。

本地维护 `ofd-renderer.js`，保留上游来源和 Apache License 2.0 许可。按命名空间 URI 识别元素，按资源 XML 与 BaseLoc 解析内部路径，保留对象顺序并按规范排列模板及图层；补充基本 DrawParam 继承及 S 起点。缺页、缺图、无效字形或未实现内容明确失败；ZIP、XML、对象、字体和图片均有限预算。相同图片只解码/内嵌一次，单图 50 MP、文档不同图资源合计 100 MP 在完整解码前检查。进行中取消可中止解析、渲染及所属子进程。

`ofd-convert.js` 在隔离临时目录生成候选，核对页数并逐页 Poppler 栅格化。实际应有内容而全白的页报 `OFD_OUTPUT_BLANK`，正确声明的空白或全透明内容可以保留。每页使用独立图片路径，避免 Sharp 缓存把前页内容当成后页。成功校验后才发布，保护既有目标；HTTP 失败返回 422 且不登记下载项。

诊断脱敏保留可信时间、级别、事件及 ENOENT/EPERM 等系统错误，不保留路径、文件名或任意附加内容。依赖锁定更新 multer 2.4.0、相关 brace-expansion 修补版，通过锁文件固定生产依赖，保持独立构建可复核。

## 回归与验收边界

仓库包含专门构造的 [OFD fixtures](../tests/fixtures/ofd/)，不包含用户原文件。可复核入口：

- [渲染器回归](../tests/ofd-renderer.test.js)：资源 BaseLoc、命名空间、对象顺序、默认属性、透明图片、S/M 起点、重复图片嵌入和取消。
- [可见性回归](../tests/ofd-visible-output.test.js)：页数、白色遮挡后的假成功、多页缓存及声明空白页。
- [HTTP 完整性回归](../tests/ofd-http-integrity.test.js)：缺页或缺图失败时不登记下载，正常结果按验证顺序发布。
- [转换回归](../tests/ofd-convert.test.js) 与 [诊断脱敏回归](../tests/diagnostics.test.js)。

不保证任意 OFD 完整支持。复杂签章、注释、裁剪、旋转或非等比文字等未实现内容明确拒绝；整页非白检测不等于任意复杂遮挡或所有局部内容的视觉等价证明。原始用户 OFD 未参加此次受控复现，已知实现缺陷的修复不能外推其所有变体。
