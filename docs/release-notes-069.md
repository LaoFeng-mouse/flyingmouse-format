# FlyingMouse Format v0.6.9（商店稳定性修复版）

## 修复
- **微软商店版启动可靠性**：偏好设置无法保存时（如系统目录重定向导致的跨设备写入失败）不再连带打断整个启动流程——引擎检测、版本显示照常，界面给出「本次仍可正常转换」的友好提示，不再误报「检测失败」。
- **商店版 LibreOffice 引擎缓存**：按版本隔离缓存目录并校验完整性标记，升级后不再沿用旧引擎；复制中断留下的半套缓存会被清理重建，杜绝「越重启越坏」的顽固故障。
- **设置并发写入**：同时改语言与保存目录等不再互相覆盖丢失；无变化时不再重复写盘。
- **Win7 构建校验**：修复 0.6.8 版本号同步遗漏导致的构建门禁失败（不影响已发布安装包）。

## 工程
- 版本升级改为原子化脚本一次同步全部清单与文档，并新增 CI 一致性守卫，杜绝同类漏改。
