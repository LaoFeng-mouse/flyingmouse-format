# 微软商店（Microsoft Store）上架操作清单

更新日期：2026-08-06
目标：把 FlyingMouse Format（飞鼠格式）上架到微软商店

## 一、你需要自己做的（账号归属你，必须本人操作）

### 第 1 步：注册开发者账号（约 20-30 分钟）
1. 打开 https://partner.microsoft.com
2. 用微软账号登录（没有就注册一个，建议用你的常用邮箱）
3. 点「成为开发者 / 注册开发者账户」→ 选择「个人（Individual）」账户类型
4. 填写：
   - 开发者显示名称：LaoFeng（商店里展示的发布者名字）
   - 联系邮箱 / 国家地区：中国
   - 验证手机号
5. 支付注册费：19 美元（一次性，约 140 元人民币），需要信用卡（Visa/Mastercard）
   - 没有国际信用卡的话，国内有些虚拟信用卡服务可用（如一些出海工具平台）
6. 完成注册后，进入 Partner Center 控制台

### 第 2 步：记录关键信息（给我，用来配置打包）
注册完成后，到 Partner Center 的「账户设置」里找到并告诉我：
- Publisher ID（一串数字，类似 9ABCDEFG1234）
- 发布者显示名（Publisher Display Name）
- 你的微软账号登录邮箱（仅用于我理解归属，不需要密码！）

### 第 3 步：创建应用条目
1. Partner Center →「应用程序和游戏」→「新应用」→「创建新应用」
2. 系统会生成一个「应用 ID/名称」，记下来给我（用于配置 identityName）

## 三、提交应用（拿到账号后一起做）

### 第 4 步：正式打包 MSIX
我根据你的 Publisher ID 更新打包配置，生成正式签名的 .msix 文件：
- 签名证书发布者名必须与账号的 Publisher ID 匹配
- 生成后你在本机双击测试安装一次

### 第 5 步：Partner Center 上传
1. 应用条目 →「提交」→ 上传 .msix 包
2. 填写商店列表信息（我提供文案，你粘贴）：
   - 名称：FlyingMouse Format（飞鼠格式）
   - 简短说明 / 详细说明：见上架材料包
   - 类别：工具 → 实用工具
   - 搜索词：格式转换、文件转换、OCR、PDF、WPS
   - 截图：主界面 + 批量转换（至少 1 张，推荐 3-5 张）
   - 应用图标：512x512 PNG
   - 隐私政策 URL：https://laofeng-mouse.github.io/flyingmouse-format/privacy-policy.html（需要先开 GitHub Pages，见下）
   - 支持 URL：https://github.com/LaoFeng-mouse/flyingmouse-format
3. 年龄分级问卷：按提示回答（工具类一般选「所有年龄」相关选项）
4. 点「提交以供认证」

### 第 6 步：等待审核
- 微软审核一般 1-3 个工作日
- 审核通过后应用在商店上线，用户搜索「FlyingMouse Format」或「飞鼠格式」即可找到

## 五、常见问题

- 注册费能退吗？不能，19 美元是一次性注册费
- 个人账户能发布免费应用吗？能，免费应用发布不额外收费
- 需要代码签名证书吗？不需要自己买！微软商店自动签名，这是选商店的核心原因
- 中国区能搜到吗？能，微软商店全球可用；如果只想中国区可见，提交时可选择市场
- 应用免费还是收费？建议先免费（当前 0 星阶段，先积累用户）
