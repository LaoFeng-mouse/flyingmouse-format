## 用户安装故障

旧 v0.2 商店包在“检查依赖项”阶段出现 `0x8007041D` 时，错误含义是 Windows 服务请求超时，不等同于缺少 VC++、.NET 或 APPX 框架依赖。已检查的 v0.2.1 Manifest 仅声明 `Windows.Desktop` TargetDeviceFamily，没有 Framework `PackageDependency`。优先让用户重启电脑，并检查 Microsoft Store Install Service、Windows Update、BITS 与 Delivery Optimization 服务；再执行商店“修复/重置”、`wsreset.exe` 和 Windows 更新。若仍失败，应收集 Windows 版本、商店诊断信息和事件查看器日志，不要通过随意补装依赖包掩盖服务故障。
