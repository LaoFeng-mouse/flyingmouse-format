# v0.6.3 Release Notes

> 合规版（部分格式已下架）。音频仅支持普通格式转换，不支持其他音乐平台的加密特殊格式。
> 仅供个人免费使用，禁止商业售卖/转卖/套壳。请支持正版音乐。

## 更新内容（2026-08-20）

### Word 转 Markdown：大纲（标题结构）恢复
- **修复**：使用自定义标题样式的 Word 文档（如「一级标题」「二级标题」等中文样式名，
  WPS/笔记软件常见）转 Markdown 时，标题被当成普通正文段落，转换结果丢失标题层级，
  Typora 等编辑器的「大纲」面板只剩零散标题。
- **新行为**：自动识别文档内置的标题样式（含标准 Heading、中文「一级标题…六级标题」、
  「半括号标题（五级）」等自定义命名），按层级映射为 Markdown 的 `#`~`######` 标题。
  实测 188 个标题的笔记文档转换后大纲完整保留。
- 普通文档转换结果不受影响。

### 其他
- 构建门禁修复：CI 测试任务改为先恢复转换引擎再跑全量测试（此前引擎缺失导致部分
  真实转换测试误报失败，不影响已发布版本）。

### 回归保障
- 全量测试通过（含新增「自定义中文标题样式转 Markdown」回归用例）。
- docx→MD 图片外置（v0.6.2 引入）与 ICO 增强、内置 PDF 引擎（docengine）等均保持。
