## 更新内容（2026-08-20）

### Word 转 Markdown：自动编号恢复（第 X 章 / 1.1 / 1.1.1）
- **修复**：WPS / Word 生成的文档中，标题层级编号（如「第 1 章」「1.1」「1.1.1」「1）」「（1）」）
  是文档的自动编号，不在标题文本里。此前转换 Markdown 时编号全部消失，只剩标题文字
  （如「1.1 是什么」变成「是什么」），目录层级数字丢失。
- **新行为**：转换时自动解析文档的多级编号定义，按文档顺序还原每个标题的编号前缀，
  与标题文本一起写入 Markdown（`# 第 1 章 xxx`、`## 1.1 xxx`、`### 2.1.1 xxx`）。
  支持阿拉伯数字 / 罗马数字 / 中文计数等常见编号样式；手动输入编号的标题不会被重复添加。
- 实测 188 个标题的 WPS 笔记文档转换后编号与大纲完整保留（逐行核对 188/188）。

### 回归保障
- 全量测试通过（含新增「WPS 自动编号标题转 Markdown」回归用例）。
- docx→MD 图片外置（v0.6.2）、大纲恢复（v0.6.3）、ICO 增强、内置 PDF 引擎（docengine）等均保持。
