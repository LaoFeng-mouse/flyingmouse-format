## 中文短描述

鼠鼠主题的本地离线文件格式转换工具，支持图片、文档、表格、演示文稿、PDF、音视频、OCR 与批量处理，并可记住常用目标格式和保存目录。

## English short description

A mouse-themed offline file converter for images, documents, spreadsheets, presentations, PDFs, audio, video, OCR, and batch workflows, with remembered format and save preferences.

## 功能要点

- 鼠鼠会根据上传、识别、批量、OCR、成功和失败状态切换动作。
- 使用本地 FFmpeg、LibreOffice、Poppler、Tesseract、Sharp 等引擎处理文件。
- 支持批量队列、逐文件结果、单独保存和保存全部。
- 按源扩展名分别记忆目标格式；用户改选后自动更新默认值。
- 记住上次保存目录。
- 支持简体中文和 English，并记住语言选择。
- 文件在本机处理，不上传到云端转换服务。
- PDF → Excel 提供智能表格提取，并对扫描件、复杂表头和合并单元格明确提示适用边界。
- 内置图片、批量、PDF 与 OCR 资源上限，避免异常文件耗尽内存。

## 安装说明

1. 下载并运行安装包。
2. 按向导选择安装目录。
3. 从桌面或开始菜单启动 FlyingMouse Format。
4. 拖入文件，选择目标格式，转换后选择保存位置。
