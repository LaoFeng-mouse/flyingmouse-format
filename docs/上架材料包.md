## 三、软件描述（长，用于商店详情页）

FlyingMouse Format（飞鼠格式）是一款 Windows 万能文件格式转换工具，内置 FFmpeg、LibreOffice、Poppler、Tesseract 转换引擎，完全离线运行，无需联网即可完成绝大多数格式转换。

【主要功能】
- 图片转换：jpg / png / webp / avif / tiff 互转，可转 PDF、TXT（OCR 文字识别）
- 文档转换：doc / docx / wps / rtf / odt 转 PDF、DOCX、TXT、HTML
- 表格转换：xls / xlsx / et / ods / csv 转 PDF、XLSX、CSV、HTML
- 演示转换：ppt / pptx / dps / odp 转 PDF、PPTX、HTML
- PDF 处理：文字型 PDF 转 Excel（表格提取）、TXT、HTML；扫描版 PDF 可 OCR 转文本；页面可导出 PNG/JPG 压缩包
- 音视频转换：mp3 / wav / flac / m4a / ogg 等音频互转，mp4 / mkv / webm / mov 等视频互转
- 任意文件：封装为 ZIP 压缩包
- 批量转换：一次选择多个文件，队列逐个处理，实时进度条与失败原因展示
- 拖拽即用：把文件拖进窗口，自动识别可用目标格式

【产品特色】
- 完全离线：所有转换引擎内置，断网可用，数据不出本机
- 安全可靠：沙箱隔离 + 严格内容安全策略，本地服务仅监听 127.0.0.1
- 转换后由用户选择保存位置，支持同名文件自动加序号避免覆盖

## 五、安装说明

1. 下载安装包后双击运行
2. 按向导完成安装（可选安装目录）
3. 安装后桌面出现 "FlyingMouse Format" 快捷方式
4. 拖入文件 → 选择目标格式 → 开始转换 → 选择保存位置

注意：当前版本未做代码签名，首次运行 Windows SmartScreen 可能提示"已保护你的电脑"，选择"更多信息 → 仍要运行"即可。
