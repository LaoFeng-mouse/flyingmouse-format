## 〇、当前版本定位

Mahiro Format 已恢复 NCM / KGG / MFLAC / MGG / KGMA / MMP4 / KWM / VPR 特殊音乐容器兼容，同时明确以下边界：

- 所有特殊音乐容器均标记为“不稳定/实验性”，必须提示用户保留源文件并复核结果。
- 只允许处理用户合法取得且有权使用的文件；不宣传“破解、绕过付费、免费下载 VIP”等用途。
- Microsoft Store 构建继续隐藏并拒绝这些入口，商店材料不宣传相关能力。
- musicex 变体可能需要 QQ 音乐登录凭据；凭据不得写入仓库、日志或诊断报告。
- VPR 当前最多覆盖约 64 MiB 音频数据，且真实样本覆盖不足。

## 五、常见问题
- **Q：特殊音乐格式稳定吗？** A：不稳定。客户端版本、密钥、凭据、账号权限与容器变体都会影响结果；必须保留源文件并复核输出。
- **Q：为什么有些 KGG 或 musicex 文件无法转换？** A：KGG 密钥可能只存在于下载歌曲时的本机酷狗数据库；musicex 凭据可能过期或账号没有对应音质权限。
- **Q：可以用来处理任意来源文件吗？** A：不可以。只处理你合法取得且有权使用的文件，并遵守音乐平台条款和所在地法律。
