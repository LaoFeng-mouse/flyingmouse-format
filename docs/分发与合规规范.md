## 一、合规底线（法律风险）

本软件含音乐解锁功能（NCM / mflac / mgg / kgma / kgg / kwm / mmp4）。根据《著作权法》第 49 条与刑法修正案（十一），**避开或破坏技术措施**存在法律风险。以下规范用于把风险降到最低：

1. **免责声明必须存在**（软件 UI、README、分发说明、诊断文件头）：
   - 「音频解锁仅支持你已购买/自有的本地文件，用于个人备份与跨设备播放」
   - 「请支持正版，尊重创作者」
   - 「本工具与各音乐平台无任何关联」
2. **文案必须用中性词**：
   - ✅ 允许：解锁、恢复、转换、解密（技术中性）、本地音频
   - ❌ 禁止：破解、免费下载 VIP 音乐、绕过付费、去版权、破解版
3. **强调使用场景是用户自有文件**：软件只处理用户本地已有的文件，不从网上下载音乐。
4. **作者署名保留**：作者统一为「牢蜂（LaoFeng）」，**不在分发物上写抖音号/联系方式**（降法律风险，举报渠道走 GitHub Issues）。
5. **非商用声明保留**：仅供个人免费使用，禁止商业售卖/转卖/套壳换皮（LICENSE 已是非商用许可）。

## 五、常见问题
- **Q：为什么不在分发物上写抖音号？** A：作者身份用于著作权主张即可（LICENSE/署名），公开联系方式反而增加针对个人的法律与骚扰风险；举报倒卖走 GitHub Issues。
- **Q：软件本身会被下架吗？** A：带解密功能的软件在微软商店等平台可能过不了审核；GitHub 有 DMCA 风险（unlock-music 前例）。国内网盘以「文件转换工具」定位低调分发，功能描述中性化。
- **Q：用户拿解锁功能去解锁盗版怎么办？** A：免责声明已明确「仅支持已购买/自有文件」，软件只处理用户本地已有文件。这不能完全免责，但显著降低「恶意规避技术措施」的认定风险。
