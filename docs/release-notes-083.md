# 飞鼠格式 0.8.3 通用源码更新

作者：牢蜂（LaoFeng）。仅供个人免费使用，禁止商业售卖、转卖和套壳。

本次公开源码更新包含 ICO 转换、安全及依赖兼容修复。公开功能只支持普通音频，不包含平台专用音乐模块或登录、凭据接入。源码验证、公开安装器构建与实际发布状态分别见 [公开交接](HANDOFF.md)；这份说明不表示新安装器或 Microsoft Store 版本已经发布。

- **完善 ICO 双向转换。**常见图片可生成 16、24、32、48、64、128、256 像素的多尺寸 Windows 图标；ICO 可转回 PNG、JPG、WebP 等格式，或与图片合并为 PDF。保持比例与透明度，小图补透明边、不放大；动画取首帧和 JPEG 白底合成会提示。增加图标目录、尺寸、像素与蒙版完整性检查，不支持的编码明确拒绝。
- **修复普通媒体兼容问题。**正确识别音轨排在视频前面的输入，修正透明视频背景处理；支持普通媒体的 5.1(side) 音频转换到相应编码，保持多轨选择与提示一致。
- **完善失败与取消处理。**合并任务取消后不再发布残留结果；不可读取输入提供明确反馈。
- **加固电子书 HTML 导出。**按文档结构清理活动脚本和不安全链接，覆盖特殊标签拼接，同时保留正常正文、表格、图片及允许的链接。
- **升级依赖并保留 Excel 功能。**更新文件匹配、归档及构建工具的相关依赖。ExcelJS 保留 4.4.0 的普通与流式读写接口；修复流式写出、ZIP 元数据读取及损坏文件错误传递，避免截断 XML 被当作部分成功。

主线开发环境要求 **Node.js 22.13.0 或更新版本**。执行 `npm ci` 时自动应用受版本及文件摘要约束的四份兼容补丁，构建前再次校验。补丁内容、第三方许可和生产/构建适用范围见 [依赖补丁说明](../third-party/dependency-patches/NOTICE.md)。

本公开源码在 Windows / Node 22.23.4 下独立安装并完成验证：完整测试 **1,361 通过、0 失败、11 条件跳过**，另有 APPX 验证器 20 项通过；生产与全量 npm 审计均为 **0 告警**，依赖树和四份补丁校验通过。公开安装包尚未重建或发布，GitHub 跨平台检查按对应提交单独记录。npm 审计结果不代表原生转换引擎或整套软件零风险。

Windows 7 继续使用独立 Legacy 运行环境和锁文件，本次主线升级不构成 Win7 风险清零或实机验收；macOS、公开安装器及 Store 状态以各自实际验证与发布记录为准。
