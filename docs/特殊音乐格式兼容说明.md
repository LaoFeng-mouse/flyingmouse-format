# Mahiro Format 特殊音乐格式兼容说明

> 这些功能均为不稳定的实验性兼容功能。客户端升级、容器变体、账号权限、凭据过期或样本覆盖不足都可能导致失败。请保留源文件并复核输出，只处理你合法取得且有权使用的文件。

原作者：牢蜂（LaoFeng）。Mahiro Format 升级与维护：YKZStudio。

## 支持范围

| 输入格式 | 处理方式 | 已知边界 |
|---|---|---|
| NCM | 常规 NCM 本地解封装；保留可用的标题、歌手、专辑和封面 | 仅保证兼容 `music.163.com` 对应客户端生成的文件；Audio Vivid / AV3A 音轨仅支持 Windows |
| KGG | 使用本机酷狗 `KGMusicV3.db` 中与文件匹配的密钥解密 | 密钥不在 KGG 文件内；必须能访问下载该歌曲时的本机酷狗密钥库 |
| QQ 音乐 QMC v1 | TKM、BKC 与十六进制扩展名使用 128 字节静态密钥流本地处理；覆盖 `0x7fff` 偏移边界 | 只覆盖公开的 QMC v1 静态密钥格式；输出按 MP3 / FLAC / OGG / WAV / M4A / AAC / APE / WMA 魔数复核 |
| QQ 音乐 QMC2 | MFLAC / MGG / MMP4 / QMC 系的 PcV1Legacy、QTag 和 EncV2 内嵌密钥变体可离线处理；musicex 通过 QQ 音乐接口换取密钥 | musicex 需要有效的 QQ 音乐网页版登录凭据，凭据和账号音质权限会影响结果 |
| KGMA | 支持 `crypto_version=3`、`crypto_slot=1`，密钥位于文件头，可离线处理 | 其他版本或槽位会明确拒绝 |
| KWM | 支持 `yeelion-kuwo-tme` 容器；优先使用文件头密钥，失败时从重复静音密文块恢复 32 字节循环掩码并用容器魔数交叉验证 | 掩码恢复依赖文件中存在可识别的重复静音块；没有有效候选时明确拒绝，不输出未验证数据 |
| VPR | 使用 KGM/VPR 掩码和文件头密钥本地处理 | 当前掩码覆盖最多约 64 MiB 音频数据；没有足够真实样本，稳定性最低 |

所有特殊格式都会在界面能力表中标记为“不稳定/实验性”，转换成功后也会附带复核提示。Microsoft Store 构建继续隐藏并拒绝这些入口。

## QQ 音乐凭据

MFLAC、MGG 或 MMP4 报错 `MFLAC_EKEY_REQUIRED` / `MFLAC_EKEY_NETWORK` 时，应用会自动打开图文教程。

1. 在电脑浏览器打开 `https://y.qq.com`，登录下载歌曲时使用的 QQ 账号。
2. 按 `F12` 打开开发者工具，选择 **Application / 应用程序**。
3. 展开 **Storage → Cookies**，选择 `https://y.qq.com`。
4. 复制 `qm_keyst`；新版登录可能使用 `psrf_qqmusic_key`。同时复制 `uin`。
5. 在桌面创建 `QQ音乐_登录cookie.txt`，内容示例：

   ```text
   uin=你的QQ号; qm_keyst=你复制的qm_keyst值
   ```

6. 重新转换。凭据过期后需重复以上步骤。

可用环境变量 `FLYINGMOUSE_QQ_COOKIE` 指定其他凭据文件路径。该内部兼容变量名为避免破坏旧配置而保留。

凭据只应保存在本机，不要提交到仓库、发送给他人或写入诊断报告。musicex 链路只向 QQ 音乐接口提交歌曲标识和登录凭据，不上传音频文件。

## KGG 密钥库

默认会尝试读取 `%APPDATA%\KuGou8\KGMusicV3.db`。自动发现失败时，按 [酷狗 KGG 密钥库手动指定教程](酷狗KGG密钥库手动指定教程.md) 设置 `FLYINGMOUSE_KGG_DB_PATH`。该内部兼容变量名为避免破坏旧配置而保留。

KGG 密钥与歌曲及客户端数据库绑定。文件来自另一台设备、数据库已清理或歌曲不是由本机客户端下载时，无法仅凭 KGG 文件恢复密钥。

## VPR 来源与限制

VPR 算法与 `kgm.mask` 资源改编自 MIT 许可的 [Unlock Music KGM/VPR 实现](https://git.dov.moe/Mirror/unlock-music/src/commit/942e43fa161fc3305ec5849f8a07dd1689bb874b/src/decrypt/kgm.ts)。完整版权与许可文本随包保存在 [`public/assets/kgm-mask-LICENSE.txt`](../public/assets/kgm-mask-LICENSE.txt)。VPR 在旧版项目文案中被列为下架格式，但现有仓库历史中没有可直接恢复的 VPR 模块，因此 Mahiro Format 补充了兼容实现并将其明确标记为最低稳定级别。

## QMC v1 与 KWM 参考实现

QMC v1 静态密钥表、`0x7fff` 偏移边界语义和 KWM 旧版掩码恢复思路参考 MIT 许可的 [HRuiCcc/music-geshizhuanhuan](https://github.com/HRuiCcc/music-geshizhuanhuan)。完整 MIT 许可文本随包保存在 [`public/assets/music-geshizhuanhuan-LICENSE.txt`](../public/assets/music-geshizhuanhuan-LICENSE.txt)。
