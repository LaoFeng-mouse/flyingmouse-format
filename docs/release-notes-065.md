# v0.6.5 Release Notes

> 合规版（部分格式已下架）。音频仅支持普通格式转换，不支持其他音乐平台的加密特殊格式。
> 仅供个人免费使用，禁止商业售卖/转卖/套壳。请支持正版音乐。

## 更新内容（2026-08-27）

### 大量图片合并 PDF 不再内存溢出
- **修复**：此前把几十张图片（手机截图、照片等）合并成一个 PDF 时，图片一多（约 53 张左右）
  就会因内存不足报错「Failed to allocate memory」——转换过程会把所有图片数据一次性放进内存，
  数量越大越容易崩。
- **新行为**：改为逐张解码、即时写入、边转边存，内存占用与图片数量无关。现在合并任意数量的
  图片都能顺利完成，不受张数限制。
- 图片仍以原始分辨率整页保存，不压缩、不缩图，转出来的 PDF 画质不打折扣。

### 修复合并 PDF 开头多一张空白页
- **修复**：不插入空白页时，部分场景会在生成的 PDF 开头多出一张空白页，已彻底修复。

### 回归保障
- 全量测试通过（含新增「60 张图片批量合并不因数量失败」回归用例）。
- 其它既有转换能力均保持。
