# 飞鼠格式 0.8.5：PDF→Word 内容校验与 Office 长路径修复

作者：牢蜂（LaoFeng）。仅供个人免费使用，禁止商业售卖、转卖和套壳。

本轮目标为 Windows 10/11 x64 完整普通版。构建、测试和公开下载状态统一见 [现役交接](HANDOFF.md)。

- PDF→Word 保留金额小数点、负号、百分号等覆盖检查，并核对重复文字数量，减少正文遗漏被误判成功。
- 隐藏文字、零宽内容和不属于正文的节点不能证明文档有可见正文。最终文字回退也要通过完整性检查。
- 无法确认矢量正文完整保留时明确报错，不提供可能只剩页脚的“成功”结果。复杂图形可能被保守拒绝；可换用含可选文字的 PDF 或先 OCR。
- 包含此前 0.8.4 候选的 Office 长路径修复：深层临时目录和长文件名使用任务专属短中间路径，保留原文件与最终名称。
- 整理 README、文档索引和交接记录，区分公开源码、实际安装包、商店候选及本地专用变体。

本轮不发布 Lite、Win7、macOS 或 Microsoft Store 包。PDF 复杂样式和所有 Word/WPS 版本不能由一次检查普遍保证；Issue #85 的原文件仍未取得，不声称已确认其唯一根因。

仅支持普通音乐格式转换，不支持其他音乐平台的加密特殊格式。请支持正版音乐，尊重创作者；本工具与各音乐平台无任何关联。安装包未签名，可使用同页 SHA256SUMS.txt 核验。
