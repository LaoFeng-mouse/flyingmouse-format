# FlyingMouse Format v0.5.5（满血版）

## 修复
- **保存不再报 404**：转换产物在程序运行期间**永不过期**——放多久都能保存；退出软件时才清理临时文件，下次启动自动回收残留。旧版「转完没过一会儿点保存全部就 404」的问题从根上去除（批量转很久、中途离开回来再保存均安全）。
- **批量保存不再一票否决**：个别文件失败会跳过并列出明细（哪些存了、哪个为什么失败），不再整批报失败。
- **程序重启后保存**得到明确提示「该转换结果已失效（程序可能重启过）」，不再是裸状态码。
- **单实例锁**：二次启动自动聚焦已有窗口，杜绝双开互踩导致产物丢失。
- **图片拼的 PDF / 扫描件 PDF 转 Word**：识别引擎偶发崩溃或失败时，自动回落 OCR 文字识别路线，大概率直接出可用 Word；失败原因也会写入诊断日志。转 Excel 对无表格 PDF 的报错补充了「请改用 PDF 转 Word / PDF 转 TXT」的指引。
- **OFD 批量转换**：修复同一程序内第 2 个及以后 OFD 文件转 PDF 文字层失效（不可复制检索）的问题。
- **上传文件名**：韩文/阿拉伯文/俄文/emoji 文件名不再乱码；挪威语等真 latin1 文件名不再被误转。
