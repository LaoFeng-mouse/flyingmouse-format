# v0.6.2 Release Notes

> 合规版（部分格式已下架）。音频仅支持普通格式转换，不支持其他音乐平台的加密特殊格式。
> 仅供个人免费使用，禁止商业售卖/转卖/套壳。请支持正版音乐。

## 更新内容（2026-08-20）

### Word 转 Markdown：含图片文档修复
- **修复**：含大量截图的 Word 文档转 Markdown 时，图片以超长单行 base64 内嵌，
  生成的文件过大（实测 37 张图约 3.3MB、单行 26 万字符），Typora 等编辑器提示
  「文件过大」无法打开。
- **新行为**：图片自动外置到 md 同目录的 `<文件名>.assets/` 文件夹，
  Markdown 内改为相对路径引用（`![](文件名.assets/image-1.png)`）。
  转换产物变为「md 文件 + 同名 .assets 图片文件夹」，保存时自动一并保存，
  图片完整保留，md 体积与行长度恢复正常（实测 3.3MB → 89KB，Typora 正常打开）。
- 纯文字文档不受影响，转换结果与之前一致。

### 回归保障
- 全量测试通过（含新增「带图 docx 转 Markdown 图片外置」集成用例与安全边界用例）。
- 内置 PDF 引擎（docengine）、docstructure 引擎、ICO 转换增强等均与 v0.6.1 一致。
