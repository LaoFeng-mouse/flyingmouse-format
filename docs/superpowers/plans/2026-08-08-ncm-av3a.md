# NCM Audio Vivid Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert official NetEase NCM files whose decrypted payload is an `av3a` Audio Vivid M4A into the app's existing audio targets offline.

**Architecture:** Extend NCM payload sniffing to ISO BMFF, add a focused MP4 sample-table extractor, decode the extracted AVS3-P3 elementary stream to WAV with a bundled helper, then reuse the current FFmpeg media conversion. Temporary artifacts stay inside the existing per-conversion NCM directory.

**Tech Stack:** Node.js buffers and filesystem APIs, Node test runner, AVS3-P3 Windows helper, bundled FFmpeg, Electron Builder.

---

### Task 1: Recognize M4A NCM payloads

**Files:** `ncm-format.js`, `tests/av3a-format.test.js`

- [ ] Write a failing test that passes an ISO BMFF `ftyp` header to exported `detectAudioFormat()` and expects `m4a`.
- [ ] Run `node --test tests/av3a-format.test.js`; expect failure because the API is missing.
- [ ] Recognize bytes 4-7 equal to `ftyp`, return `m4a`, and export the helper.
- [ ] Run the focused test; expect PASS.

### Task 2: Extract an AV3A elementary stream from M4A

**Files:** `av3a-format.js`, `tests/av3a-format.test.js`

- [ ] Build a minimal test MP4 containing `av3a`, `stsz`, `stsc`, `stco` and two known samples; assert codec detection and exact extracted bytes.
- [ ] Add `co64`, malformed count and out-of-bounds tests, then run them and observe the missing-module failure.
- [ ] Implement bounded box parsing, track selection and strict sample-table extraction.
- [ ] Run focused tests; expect all cases PASS.

### Task 3: Route AV3A NCM through the decoder

**Files:** `server.js`, `av3a-format.js`, `tests/av3a-format.test.js`, `package.json`, `bin/avs3/*`

- [ ] Write failing tests for helper path resolution and helper invocation with `-if`, `-of` and `cwd` set to the model directory.
- [ ] Implement resolution order: environment override, packaged `resources/avs3`, repository `bin/avs3`.
- [ ] For a decrypted `m4a` whose codec is `av3a`, extract `native.av3a`, decode to a non-empty `native.wav`, and pass the WAV to existing `convertMedia`; leave all other formats unchanged.
- [ ] Add the helper executable, `model.bin`, full third-party notice, build file entry and `extraResources` entry.
- [ ] Run focused tests and then `npm test`; expect zero failures.
