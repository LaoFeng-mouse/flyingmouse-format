# FlyingMouse Format 鼠鼠版功能整合与双语设计

## 目标

本次只处理 FlyingMouse Format，不修改鼠鼠打印。GitHub 主项目恢复 `v0.2.1` 时期的原版鼠鼠 UI，并在该界面上保留和完善当前功能：标准 NCM、AV3A/Audio Vivid NCM、目标格式记忆、保存目录记忆、完整离线转换能力。新增中英文切换和双语项目介绍，最终以 `v0.3.1` 替代方向错误的 `v0.3.0`，成为 GitHub 最新下载版本。

## 版本边界

- 产品名称继续使用 `FlyingMouse Format`。
- GitHub `main` 恢复鼠鼠版为正式主版本，不保留闲鱼交付版视觉作为默认界面。
- 不处理其他网站生成的非标准 NCM；只保证网易云官方客户端标准 NCM 及已验证的 AV3A 变体。
- 本次不修改、不打包、不发布鼠鼠打印。
- 不改变现有离线处理、同源下载、Electron 沙箱和 IPC 信任边界。

## 鼠鼠 UI 恢复

- 以 `fb62e3a`（`v0.2.1`）的 `public/index.html`、`public/styles.css` 和鼠鼠状态设计为视觉基线。
- 恢复鼠鼠头像、文件上传/分析/转换/成功/失败等状态图，以及原版粉色、奶油色、粗描边视觉。
- 保留当前版本新增的工作流能力、批量转换、进度、目标格式记忆和保存逻辑；不能直接回退整个应用文件。
- 语言切换作为小型设置控件加入顶部区域，不重新设计整体布局。

## 中英文设置

- 新增独立的 `public/i18n.js`，集中维护 `zh-CN` 与 `en-US` 文案，避免在业务逻辑中散落条件判断。
- 语言优先级：用户保存的选择 > 系统语言；系统非中文时默认英文。
- 使用版本化 localStorage 键保存语言，应用重启后恢复。
- 静态标题、按钮、工作流步骤、提示、格式说明和动态状态均通过翻译键渲染。
- 转换引擎返回的技术错误保留原始细节，外层操作提示按当前语言显示，避免翻译掩盖诊断信息。
- `document.documentElement.lang` 随选择同步为 `zh-CN` 或 `en-US`。

## NCM 与操作记忆

- 保留 `ncm-format.js`、`av3a-format.js`、AV3A 解码资源和当前服务器路由。
- 继续按源扩展名分别记忆目标格式；手动修改即覆盖该源格式的默认目标。
- 继续记忆最近一次成功保存的目录；取消保存、损坏设置或失效目录不能覆盖有效记忆。
- 鼠鼠状态图与转换生命周期重新连接：选择、分析、转换、批量、OCR、PDF、成功、失败。

## GitHub 项目介绍

- README 先提供中文完整说明，再提供 English 区块，并在顶部提供语言锚点。
- 两种语言均覆盖：离线隐私、主要格式、快速开始、系统要求、构建限制、测试边界、第三方组件与未签名提示。
- 对专有音乐容器能力采用中性兼容性描述；不宣传规避 DRM。
- 明确源码仓库未包含 FFmpeg、LibreOffice、Poppler、Tesseract 等大型引擎，普通用户应下载 Release 安装包。

## 测试与验收

- 为语言检测、语言持久化、缺损存储回退和静态/动态翻译增加单元测试。
- 静态测试要求鼠鼠素材、鼠鼠状态逻辑、语言控件和安全边界存在。
- 运行完整 `npm test`，要求零失败。
- 用三首用户提供的 AV3A NCM 重新完成 NCM -> MP3 全文件解码校验。
- 构建 `v0.3.1` NSIS，检查 ASAR、AV3A 资源、模型与许可证。
- 启动 `win-unpacked`，通过真实打包版转换接口验证至少一首 AV3A NCM。
- 截图检查中文和英文两种界面：文字不溢出、控件不重叠、鼠鼠状态图可见。
- 更新桌面快捷方式后确认目标 EXE 的产品版本为 `0.3.1.0`。
- 推送 GitHub `main`，发布 `v0.3.1` 安装包与 SHA256，回读 `releases/latest` 和远程资产摘要。
