# FlyingMouse Format 0.7.0

作者：牢蜂（LaoFeng）。应用仅供个人免费使用，禁止商业售卖、转卖或套壳；独立第三方引擎保留各自许可证。

本版解决 PDF 转 Word 出现逐字换行、漏字与标题顺序错误，以及 Markdown 转 Word 丢失表格、公式、列表和代码格式的问题。Markdown 使用随包提供的 Pandoc 3.11，将数学表达式写为 Word 可编辑公式；PDF 原生结果增加文字覆盖检查，必要时重建段落，混合文字/扫描文件按页补充 OCR。

设置中新增浅色、深色、跟随系统三种外观。保存失败后的本地偏好继续保留并重试；旧请求响应和延迟初始化不会覆盖新选择。角色沿用经核对的独立资源，禁止把含错误身体标记的工厂合成图当作默认界面或角色模板。

其他修复包括：Markdown 改名保存后的图片链接、附件失败时保护旧文件、CLI 附件完整保存、断流关闭和长文件名；LibreOffice 缺失/损坏/空清单不再无验证放行，真实检查 PDF 页数和预期文字，构建自动写入 ICU 等关键依赖清单；版本写盘失败回滚包含部分写入的当前文件。JSON 大数/小数保真、电子书章节及 ZIP 数据描述符、MOBI 压缩、子进程大量诊断输出处理均有针对性修复。增加 JFIF/JPE 输入别名，更新依赖消除已知生产依赖审计项。

验证包括真实 Windows 转换、DOCX 结构内容断言、LibreOffice 渲染查看、浏览器主题交互、故障注入和 APPX 构建门禁。详细审查及证据边界见 [0.7.0 修复复核](audit-070-fixes.md)。

PDF 降级重建以可编辑内容和阅读顺序为目标，复杂版式仍可能变化；OCR 标点和低清扫描识别仍有误差。Markdown 远程图片不会自动联网下载，缺失本地图片会保留说明并提示；任意 HTML/CSS、TeX 宏、Mermaid 图表不承诺完整转换。MOBI HUFF/KF8、加密电子书仍不支持。Windows 7 不捆绑新版 Pandoc；macOS/Win7 设备验收与 Microsoft Store 认证不由本机 APPX 构建结果推定。
