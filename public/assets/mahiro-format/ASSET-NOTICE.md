# Mahiro theme artwork notice

The PNG artwork in this directory is AI-generated fan artwork created for the
non-commercial Mahiro Format theme on 2026-08-27. No official anime frames,
game assets, promotional illustrations, or third-party image files were used as
source material.

The sprite sheet was generated as a consistent 3 × 3 state set and then cropped
into the `idle`, `upload`, `analyzing`, `converting`, `pdf-pages`, `ocr`, `batch`,
`success`, and `error` application states. `mahiro-avatar.png` and the packaging
icons are derived from the idle state.

Mahiro Oyama / 绪山真寻 and *ONIMAI: I'm Now Your Sister!* /
《别当欧尼酱了！》 belong to their respective authors and rights holders. This
project is not official, endorsed, or affiliated with those rights holders.

Generation mode: built-in image generation, followed by deterministic cropping
and resizing for application packaging.
